# Desafío 2 – Programación Orientada a Objetos (POO)

Este diagrama representa la versión orientada a objetos del desafío anterior
**“CodeChads Academy”**.

## 💠 Clases del dominio

- **Estudiante**: modela a un alumno con sus notas, promedio y métodos de evaluación individual.
- **Academia**: representa la institución que gestiona un conjunto de estudiantes y calcula rankings.

## 🧩 Consideraciones

- Se aplicaron los principios de **POO**:
- Responsabilidad única**: cada clase tiene una función específica.
- Se mantuvo la misma lógica del desafío estructurado, pero separada por clases.
- Se usa relación **1 a muchos** entre `Academia` y `Estudiante`.
